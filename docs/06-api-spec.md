# EduForge AI — API Specification

Base: `/api/v1` · Content type `application/json` unless stated · All IDs are UUIDv4.
OpenAPI 3.1 is generated by FastAPI at `/api/v1/openapi.json`; this document is the contract that
generated file must match.

---

## 1. Endpoint summary

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/documents` | Upload and register a source document |
| `GET` | `/documents/{document_id}` | Document metadata + parse stats |
| `POST` | `/jobs` | Start a pipeline run |
| `GET` | `/jobs/{job_id}` | Job status snapshot |
| `GET` | `/jobs/{job_id}/events` | **SSE progress stream (resumable)** |
| `POST` | `/jobs/{job_id}/cancel` | Cancel a running job |
| `POST` | `/jobs/{job_id}/retry` | Resume from the first incomplete stage |
| `GET` | `/packages/{package_id}` | The `TeacherKnowledgePackage` |
| `GET` | `/packages/{package_id}/validation` | Validation report |
| `GET` | `/packages/{package_id}/artifacts` | Artifact listing |
| `GET` | `/packages/{package_id}/artifacts/{kind}` | Download an artifact |
| `GET` | `/samples` | Pre-generated sample packages |
| `GET` | `/schema/tkp` | The published TKP JSON Schema |
| `GET` | `/healthz` · `/readyz` · `/metrics` | Ops |

## 2. Documents

### `POST /documents`
`multipart/form-data`, field `file`.

**201**
```json
{
  "document_id": "0d1f...",
  "sha256": "9c4b...",
  "filename": "physics-ch3.pdf",
  "mime": "application/pdf",
  "page_count": 24,
  "word_count": 8130,
  "detected_language": "en",
  "deduplicated": false
}
```
`deduplicated: true` means identical content was already present and the existing id is returned
(H-15). This is a `201`, not a `409` — the client's intent is satisfied either way.

**Errors**

| Code | `error.code` | Cause |
|---|---|---|
| 413 | `document_too_large` | > `MAX_UPLOAD_MB` |
| 415 | `unsupported_media_type` | Sniffed MIME not in the allow-list |
| 422 | `too_many_pages` / `parse_failed` / `empty_document` | Caps or parse |
| 429 | `rate_limited` | Per-IP limit |

### `GET /documents/{document_id}`
Returns metadata plus `outline`, `stats` (`{equations, tables, figures, headings}`), and
`chunk_count`. Does **not** return full text.

## 3. Jobs

### `POST /jobs`
Header: `Idempotency-Key: <client uuid>` (recommended; a repeat returns the existing job).

```json
{
  "document_id": "0d1f...",
  "options": {
    "period_duration_minutes": 40,
    "target_period_count": null,
    "output_language": "en",
    "curriculum_board": "CBSE",
    "include_artifacts": ["tkp_json","lesson_plan_pdf","teacher_guide_pdf","assessment_book_pdf","markdown_bundle"]
  }
}
```
All `options` fields are optional. `target_period_count: null` means "derive it" (H-08).
`output_language` drives BR-06 — values are translated, JSON keys stay English (H-11).

**202**
```json
{"job_id":"7a3e...","status":"queued","progress":0,
 "events_url":"/api/v1/jobs/7a3e.../events","created_at":"2026-07-30T18:00:00Z"}
```

### `GET /jobs/{job_id}`
```json
{
  "job_id": "7a3e...",
  "document_id": "0d1f...",
  "status": "running",
  "current_stage": "lesson-generation",
  "progress": 58,
  "stages": [
    {"stage":"document-intelligence","status":"completed","duration_ms":1840},
    {"stage":"educational-classification","status":"completed","duration_ms":4200},
    {"stage":"knowledge-extraction","status":"completed","duration_ms":31500},
    {"stage":"teaching-planner","status":"completed","duration_ms":12100},
    {"stage":"lesson-generation","status":"running","completed_items":3,"total_items":5},
    {"stage":"activity-generation","status":"pending"}
  ],
  "package_id": null,
  "usage": {"tokens_in": 184300, "tokens_out": 41200, "cache_read": 121000, "cost_usd": 2.14},
  "warnings": [],
  "error": null
}
```

`status ∈ {queued, running, succeeded, succeeded_partial, failed, cancelled}`.
`succeeded_partial` means the package exists but is incomplete — budget exhausted or an artifact
failed to render. The UI shows it as a success with a caveat, not as a failure.

### `GET /jobs/{job_id}/events` — SSE (FR-14, H-02)

Request headers: `Accept: text/event-stream`, optional `Last-Event-ID: <seq>`.

```
id: 41
event: progress
data: {"stage":"knowledge-extraction","progress":30,"message":"merged 4 sections","ts":"..."}

id: 42
event: progress
data: {"stage":"lesson-generation","progress":60,"message":"period 3 of 5","ts":"..."}

: heartbeat

id: 57
event: completed
data: {"stage":"completed","progress":100,"package_id":"c81a...","status":"pass_with_warnings"}
```

Contract guarantees:
- Every `data` payload contains **`stage` (string) and `progress` (integer 0–100)** — exactly the
  shape the assignment specifies. Other keys are additive.
- `id` is the persisted `job_events.seq`. On reconnect with `Last-Event-ID`, the server replays
  every event after that seq before tailing — **nothing is lost across a refresh or a disconnect.**
- A `: heartbeat` comment every 15 s prevents proxy idle-timeout kills.
- Terminal events: `event: completed` or `event: failed`. Both close the stream.
- `event: warning` may appear mid-run (degraded stage, low-confidence classification).
- Replaying a finished job returns the whole history then closes immediately — so the UI renders a
  full timeline for a job that finished before the page opened.

### `POST /jobs/{job_id}/cancel`
**200** `{"job_id":"...","status":"cancelled"}`. In-flight model calls are abandoned at the next
await point; completed checkpoints are retained so `retry` can resume.

### `POST /jobs/{job_id}/retry`
Valid for `failed`, `cancelled`, `succeeded_partial`. Resumes from the first incomplete stage;
completed stages are not re-executed or re-billed (H-03). **202** with the same `job_id`.

Optional body `{"from_stage": "teaching-planner"}` invalidates that stage and everything after it —
used by the UI's "regenerate lesson plan" affordance.

## 4. Packages

### `GET /packages/{package_id}`
Returns the full `TeacherKnowledgePackage` (the same bytes served as `tkp_json`).
`?view=summary` returns a light envelope (classification, period titles, counts, validation status)
for list rendering.

### `GET /packages/{package_id}/validation`
```json
{
  "status": "pass_with_warnings",
  "schema_ok": true,
  "grounding_score": 0.94,
  "coverage": {"concepts_total":18,"concepts_taught":18,"objectives_total":7,"objectives_assessed":7},
  "consistency": {"duplicate_concepts":[], "prerequisite_violations":[], "timing_ok": true},
  "unsupported_claims": [
    {"path":"/knowledge/applications/2","claim":"Used in MRI machines","reason":"not present in cited chunk c_14"}
  ],
  "issues": [
    {"code":"GROUNDING_WEAK","severity":"warning","message":"1 application not supported by cited span",
     "path":"/knowledge/applications/2","stage":"knowledge-extraction"}
  ],
  "checked_at": "2026-07-30T18:11:02Z"
}
```

### `GET /packages/{package_id}/artifacts`
```json
{"artifacts":[
  {"kind":"tkp_json","mime":"application/json","bytes":184320,"status":"ready",
   "url":"/api/v1/packages/c81a.../artifacts/tkp_json"},
  {"kind":"lesson_plan_pdf","mime":"application/pdf","bytes":412880,"status":"ready","url":"..."},
  {"kind":"teacher_guide_pdf","mime":"application/pdf","bytes":690214,"status":"ready","url":"..."},
  {"kind":"assessment_book_pdf","mime":"application/pdf","bytes":233190,"status":"ready","url":"..."},
  {"kind":"markdown_bundle","mime":"application/zip","bytes":48211,"status":"ready","url":"..."}
]}
```

### `GET /packages/{package_id}/artifacts/{kind}`
Streams the artifact with `Content-Disposition: attachment`. **404** if `status != ready`.

## 5. Samples, schema, ops

### `GET /samples` (H-12, DR-06)
```json
{"samples":[
 {"package_id":"...","title":"Newton's Laws of Motion (Grade 9 Physics)","subject":"Physics",
  "pedagogy_profile":"quantitative","periods":5,"validation_status":"pass"},
 {"package_id":"...","title":"The Partition of Bengal (Grade 10 History)","subject":"History",
  "pedagogy_profile":"narrative","periods":4,"validation_status":"pass"}
]}
```
Served from seeded rows; renders with zero model calls, instantly, on a cold container.

### `GET /schema/tkp`
The published JSON Schema. `?version=1.0.0` pins; default is latest.

### Ops
- `GET /healthz` → `200 {"status":"ok"}` — liveness, no dependency checks.
- `GET /readyz` → DB reachable, migrations current, model key present. `503` with the failing check.
- `GET /metrics` → Prometheus text.

## 6. Conventions

**Error envelope** — uniform across every endpoint:
```json
{"error":{"code":"document_too_large","message":"File exceeds 25 MB limit.",
          "details":{"size_bytes":41231882,"limit_bytes":26214400},
          "trace_id":"01J8..."}}
```

**Rate limits** — `POST /documents` 10/hour/IP; `POST /jobs` 5/hour/IP; global concurrent-job cap.
`429` carries `Retry-After`.

**Auth (v1)** — optional shared access code via `X-Access-Code` when `DEMO_ACCESS_CODE` is set;
otherwise open, protected by rate limits. Package IDs are unguessable UUIDv4. Real per-teacher auth
is deliberately out of scope and noted in the roadmap.

**Idempotency** — `POST /jobs` honours `Idempotency-Key` for 24 h.

**Versioning** — path-versioned (`/api/v1`). Additive changes only within a major version.
